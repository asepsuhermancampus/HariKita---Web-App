==================================================
02. DESIGN PRINCIPLES
==================================================

Core design philosophy:

LESS DECORATION, MORE IDENTITY.

The visual system must prioritize:

- whitespace
- typography
- elegant proportions
- subtle botanical details
- fine-line illustrations
- warm neutral colors
- restrained ornamentation
- editorial composition
- premium simplicity

Avoid:

- generic wedding clipart
- excessive flowers
- excessive gold
- bride/groom illustrations
- wedding rings as primary identity
- crowns
- heart-shaped clichés
- overly decorative calligraphy
- excessive gradients
- excessive shadows
- excessive 3D effects
- glossy metallic effects
- overly ornamental frames
- crowded compositions

Flowers, leaves and ornaments are supporting visual language.

They must never overpower the HariKita identity.

18. SVG REQUIREMENTS
==================================================

For every SVG asset:

- valid SVG/XML
- correct viewBox
- scalable
- no embedded raster image
- no unnecessary filters
- no unnecessary masks
- no unnecessary clip paths
- optimized paths
- minimal anchor points
- consistent stroke width
- responsive
- recolorable where appropriate
- currentColor support where appropriate

Line illustrations should preferably use:

stroke="currentColor"

Filled elements should allow controlled color customization.

Do not permanently lock every illustration to a single gold color.

The frontend should be able to apply:

color:
var(--hk-champagne);

or:

color:
var(--hk-taupe);

where appropriate.
